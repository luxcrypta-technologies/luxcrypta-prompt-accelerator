# Modes

V1 modes are deterministic prompt templates:

- `focus`: objective-first and compact.
- `speed`: shortest useful shape.
- `precision`: explicit requirements and output contract.
- `creative`: options within boundaries.
- `debate`: multi-view tradeoffs.
- `research`: structured analysis with uncertainty.
- `code`: implementation and tests.
- `executive_summary`: recommendation, risks, options, next step.

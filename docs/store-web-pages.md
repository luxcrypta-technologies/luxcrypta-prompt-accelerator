```md
# LuxCrypta Prompt Accelerator

LuxCrypta Prompt Accelerator is a local-first browser extension that makes AI chats easier to drive.

It helps reduce repetition, preserve important constraints, strengthen continuity across longer sessions, and turn repeated prompt work into reusable workflows. The default chat-page experience stays quiet, with Advanced available when users want a clear review layer before changes are applied.

## Core Capabilities

- Always-on continuity shaping
- Human-readable Advanced review
- Redundancy reduction and objective prioritization
- Carry-forward session capsules
- Reusable workflows
- Cross-model prompt adaptation
- Visible diff and explanation
- Session-governance features for stronger continuity and novelty handling
- Local-first storage with manual export/import

## Browser Support

LuxCrypta Prompt Accelerator is packaged for Chromium-based browsers and Firefox.

Supported chat surfaces:

- ChatGPT
- Claude
- Gemini
- Grok

## What It Is

LuxCrypta Prompt Accelerator is a user-side prompt and session accelerator for AI chat workflows.

## What It Is Not

It is not a model, not hidden control over third-party AI systems, and not a release of LuxCrypta proprietary runtime systems.

## Privacy

Core behavior is local-first. The extension does not use telemetry, analytics, hidden cloud sync, or a backend service for prompt/session processing.
```

```md
# LuxCrypta Prompt Accelerator Privacy Policy

Effective date: April 29, 2026

LuxCrypta Prompt Accelerator is designed as a local-first browser extension for prompt and session workflow support.

## Data The Extension Uses

The extension may read draft prompt text and shallow page context on supported chat pages when the user triggers an action such as transform, review, apply, workflow save, capsule generation, export, or import.

The extension may store the following data locally in browser extension storage:

- Preferences
- Saved workflows
- Saved capsules
- Compact session governance state
- Compact diagnostics snapshots
- Optional local action history, if enabled

## Data The Extension Does Not Collect

The extension does not use hidden telemetry, analytics, hidden cloud sync, or a backend service for core functionality.

The extension is not designed to silently harvest full chat histories or exfiltrate prompt content.

## Data Sharing

The extension does not sell, transfer, or share user data with third parties. Core prompt/session processing is local-first.

## Export And Import

Export/import is manual and user-triggered. Users can export local workflows, capsules, preferences, compact session state, and diagnostics as JSON and import them later.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Contact

For support, visit https://luxcrypta.com/prompt-accelerator/support.
```

```md
# LuxCrypta Prompt Accelerator Support

Use this page for support with LuxCrypta Prompt Accelerator.

## Basic Troubleshooting

1. Confirm the browser extension is enabled.
2. Confirm you are on a supported chat surface: ChatGPT, Claude, Gemini, or Grok.
3. Reload the chat page after installing or updating the extension.
4. Open the extension popup and confirm the page is detected.
5. Check Options if toolbar or session governance features are disabled.

## Supported Browsers

- Chromium-based browsers
- Firefox

## Privacy

LuxCrypta Prompt Accelerator is local-first. It does not use hidden telemetry, analytics, hidden cloud sync, or a backend service for core prompt/session processing.

## Contact

For support requests, include:

- Browser and version
- Extension version
- Supported chat surface
- Action attempted
- Expected result
- Observed result
- Any visible console error
```
